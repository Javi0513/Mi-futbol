# Mi Fútbol JV32 · App Android

Proyecto Android (Trusted Web Activity) que abre https://app.monetizaplus.com como app nativa.
Cada push a esta rama compila el AAB y el APK sin firmar y los deja en la rama `android-salida`.
La firma se hace fuera del repo: el keystore y sus contraseñas nunca se suben aquí.
